# H3 云端接入说明

在视频创作台或画布的视频节点选择 **MiniMax-H3（云端 ComfyUI）**，任务会发送到当前配置的云端 ComfyUI。已有渠道中名称为 MiniMax-H3 或带后缀的 H3 模型也会走这条路线，不再调用原渠道的视频 API 或自定义脚本。其他模型沿用原来的渠道。

## 启动与使用

在项目 `web` 目录启动 Vite 后，打开 `http://127.0.0.1:3000/video`。本次已经安装依赖并启动了本地开发服务。需要重新启动时，可运行 `bun --bun run dev --host 127.0.0.1`，让项目直接使用已安装的 Bun，避免本机旧 Node 的动态库问题。构建后可用 `bun --bun run start --host 127.0.0.1` 启动预览。

1. 选择「MiniMax-H3（云端 ComfyUI）」，无需填写 MiniMax API Key。
2. 文生视频只输入提示词；图生视频按顺序上传首帧和可选尾帧；参考生视频上传参考图片，提示词可用 `<Picture 1>` 指定第一张图片。
3. 画布中先添加图片或其他参考素材，再在视频节点的「参考内容」中选择它们。参考视频/音频分别映射至 H3 的视频/音频输入。
4. 点击生成。结果可在工作台播放、下载，或保存到「我的资产」。画布和资产仍主要保存在当前浏览器本地。

尺寸按 H3 原生要求对齐到 32 的倍数，帧数按 24 fps、17k+5 对齐。例如选择 16:9 / 480p / 5 秒，实际输出为 864×480、124 帧，约 5.17 秒。现有分辨率和时长选项未增加限制；高分辨率和长视频尚未实测，不能据此承诺均适合单卡。原生节点标注的训练时长范围约为 5–15 秒。这里运行的是开放权重 H3，不等同于官方托管 2K 服务。

## 控制参数

视频创作台和画布的视频设置共用同一面板；选择 H3 后显示以下参数。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 生成声音 | 开启 | 三种模式均可用。关闭时不解码、合成输出音轨，得到静音视频。 |
| 采样步数 | 20 | 位于高级设置，接受云端原生调度器支持的 1–10000 整数；步数更多通常更慢，不保证画质更好。 |
| 随机种子 | 留空随机 | 位于高级设置。固定非负整数用于相同参数下的对比，0 有效；超过 JavaScript 安全整数范围的值会在提交前被拒绝。 |
| 参考图细节 | 自动匹配 | 仅参考模式显示。可选「保留更多」，减少大参考图的缩小程度；小图不放大，可能增加耗时。这是参考图处理尺寸，不是人物相似度或参考强度。 |

「生成声音」控制整条输出音轨。需要保留人声、引擎声等音效而只去掉背景配乐时，保持开启，并在提示词中明确「无背景音乐，保留环境音和动作音效」。关闭声音不会跳过 H3 联合音视频采样，不能据此预期明显加速。

设置随画布节点和生成记录保存；节点内清空种子会恢复随机，不会继承全局固定种子。实际提交的随机种子、步数、参考图细节和声音设置也保存在本地任务记录中。

## 连接方式

浏览器调用同源 `/comfyui`，Vite 将请求转发到云端现有 Jupyter Proxy 的 8188 入口。任务转换、参数映射和查询代码位于 `web/src/services/api/`。不需要再安装一个云端 API 服务，也未修改已有 ComfyUI 工作流编辑页。

- 固定云端地址：`web/src/constant/comfyui.ts`。
- 工作流与模型文件名：`web/src/services/api/comfyui-h3-workflow.ts`。
- 文生视频、首尾帧：`minimax_h3_fl2va_pruned_int8_convrot.safetensors`。
- 参考生视频：`minimax_h3_ref2va_pruned_int8_convrot.safetensors`。
- 编码器：`qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors`。
- 视频/音频 VAE：`minimax_h3_video_vae_fp16.safetensors`、`minimax_h3_audio_vae_fp32.safetensors`。

以上模型和原生节点在云端均已存在，无需重复下载。工作流默认使用 20 步、`res_multistep` 采样器和 `simple` 调度器，步数可在高级设置中调整，不启用 Turbo LoRA。API 图由程序按输入构建；提交到 `/prompt` 后，ComfyUI 自己负责排队执行。

云端已有 PDD-Acc 节点和 8 步示例工作流，但专用节点的 `pdd_file` 当前没有可选模型，因此尚未提供加速开关。接入需要确认专用模型注册、FL2VA/Ref2VA 权重匹配及配套采样器和调度；直接减少基础模型步数不等同于启用 PDD-Acc。

当前转发覆盖 Vite 开发和预览服务。直接发布 `dist` 到静态站点或使用原 Docker/Nginx 配置，还需要部署相应固定转发。服务端转发不携带浏览器里配置的第三方模型 API Key，也没有将 Jupyter 凭据写入代码。访问仍依赖本机到云端的网络与平台权限。

## 任务恢复

任务提交后，云端编号与执行参数保存在浏览器 IndexedDB；画布节点和视频生成记录也保存编号。刷新页面可以继续查询。网络异常或一轮等待结束时，不重新生成；视频创作台点击「继续查询」，画布使用已有的任务状态查询操作即可。

H3 每轮查询间隔 2.5 秒、最多 240 次，约 10 分钟加网络耗时。到达本轮上限后保留原任务编号，可以继续查询；页面结束等待不会取消云端任务。其他视频模型仍沿用原来的查询上限。

取回文件信息后会保存输出位置，已下载视频保存到浏览器素材存储。若在取得输出位置之前，云端历史被清空或实例丢失，本地编号本身不能保证恢复结果。停止页面查询也不会取消已提交的 GPU 任务。
